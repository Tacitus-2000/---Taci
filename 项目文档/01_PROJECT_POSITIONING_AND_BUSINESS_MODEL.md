# 01_PROJECT_POSITIONING_AND_BUSINESS_MODEL｜项目定位与商业模式

## 1. 项目定位

本项目定位为：

> **垂直行业内容营销系统定制服务**

第一阶段具体落点：

> **刑事律师短视频内容系统定制服务**

不是卖“AI 文案生成器”，而是卖一套定制化内容生产系统。

## 2. 第一阶段目标客户

第一批目标客户：

```text
个人刑事律师
```

选择原因：

```text
1. 刑事律师客单价高。
2. 客户信任成本高，内容营销有价值。
3. 律师专业表达门槛高，普通代运营难做好。
4. 用户已有律师客户和成功案例，不是从零开始。
5. 个人律师决策更快，适合第一阶段验证。
```

后续扩展顺序：

```text
个人刑事律师
↓
其他法律领域个人律师
↓
律所
↓
制造业 / 服装业 / B2B / 教育培训 / 咨询等行业
```

## 3. 商业模式

确认采用：

```text
4W 深度启动包
+
后续可选维护包
```

### 4W 深度启动包交付内容

```text
1. 客户行业与个人定位
2. 目标客户画像
3. 内容栏目设计
4. 选题矩阵
5. 初始短视频文案包
6. 客户前台账号
7. 自助生成额度
8. 内容日历
9. 风格参考入口
10. 修改反馈通道
11. 后台严格审查 AI
```

### 后续可选维护包

维护包可包含：

```text
1. 每月选题更新
2. 每月文案额度
3. 内容方向微调
4. 风格蒸馏更新
5. 后台质检规则更新
6. 内容复盘
7. 新案例 / 新素材补充
8. 账号内容日历维护
```

## 4. 为什么不卖低价工具

不能把产品包装成：

```text
AI 文案生成工具
无限生成
低价 SaaS
99 元生成 100 条文案
```

因为这样客户会认为：

```text
我自己用 ChatGPT 也能做。
```

正确包装：

```text
我们帮你搭建一套专属于你的短视频内容增长系统。
```

## 5. “文案用的人多了就不值钱”的判断

这个判断一半正确。

### 会贬值的是：

```text
通用文案
通用标题模板
通用提示词
无限生成次数
低价文案包
```

### 不容易贬值的是：

```text
客户专属定位
行业模板
内容策略
选题方法
风格档案
后台审查体系
内容资产库
交付流程
成功案例
```

所以系统应当：

```text
复用生产能力
不复用客户最终文案
```

## 6. 销售话术方向

对客户不要说：

```text
我们给你一个 AI 写文案工具。
```

而要说：

```text
我们会先帮你明确账号定位、目标客户和内容方向，再给你搭建一个专属内容系统。你可以在前台生成和查看文案，后台会持续进行内容策略和风险表达质检。
```

## 7. 核心护城河

当前确认的护城河：

```text
1. 多 Agent 内容生产工作流
2. 律师行业理解
3. 内容库
4. 高端定制交付流程
5. 未来多行业模板迁移能力
```

## 8. 长期战略

```text
刑事律师样板
↓
法律行业模板库
↓
行业内容营销模板库
↓
多行业内容增长系统
```
