# 11_PROMPT_AND_ASSET_LIBRARY_PLAN｜提示词与内容资产库规划

## 1. 为什么要做资产库

如果只做项目交付，每个客户都要从零开始。

资产库的价值：

```text
让客户越多，后台越强。
```

关键原则：

```text
复用生产能力，不复用客户最终文案。
```

## 4. 高转化开头库

示例：

```text
家人被刑拘后，很多家属第一步就做错了。
不是所有取保申请，都输在材料不全。
刑事案件里，最怕的不是慢，而是方向错。
```

## 5. 真人化表达替换库

示例：

```text
AI味：在此类案件中，应当综合判断具体事实。
真人版：这种案子不能先问能不能取保，要先看证据卡在哪一步。
```

## 6. 风险表达替换库

示例：

```text
高风险：一定能取保。
安全版：是否有取保空间，要看案件事实、证据情况和社会危险性判断。
```

## 10. 资产可见性

资产库只给 Admin 看。

Client 不看：

```text
模板库
提示词
后台结构
其他客户案例原文
```

Client 只看自己的内容结果。
