# 10_INDUSTRY_TEMPLATE_EXPANSION_PLAN｜多行业模板扩展规划

## 1. 长期方向

本系统长期不是律师专用，而是可迁移到各行业的内容营销系统。

第一阶段：

```text
刑事律师
```

后续可扩展：

```text
制造业
服装业
教育培训
医美
咨询服务
B2B 服务
企业老板 IP
```

## 2. 行业模板结构

每个行业模板包含：

```text
行业名称
目标客户类型
常见痛点
内容栏目
选题结构
文案结构
风险审查规则
风格参数
默认提示词
转化方式
```

## 3. 第一阶段模板：刑事律师

```text
行业：legal
模板：criminal_lawyer
目标客户：涉案家属、企业老板、刑事风险客户
内容栏目：家属救急、老板避坑、案例拆解、误区纠偏、面谈前准备
风险规则：不能承诺结果、不能暗示胜诉率、不能制造恐慌
转化目标：私信咨询、预约面谈
```

## 4. 制造业模板示例

```text
行业：manufacturing
目标客户：工程师、采购、项目经理、老板
内容栏目：工艺讲解、质量控制、选型避坑、案例展示、交付能力
风险规则：不能夸大参数、不能虚假认证、不能过度承诺交期
转化目标：询盘、样品申请、技术沟通
```

## 5. 服装业模板示例

```text
行业：fashion
目标客户：消费者、买手、渠道商、加盟商
内容栏目：穿搭、面料、趋势、场景、用户故事
风险规则：不能虚假宣传、不能夸大效果、保持品牌调性
转化目标：购买、私信咨询、加盟、进店
```

## 6. 迁移原则

不要复制行业表面词汇，而要复用底层逻辑：

```text
客户是谁
↓
客户为什么买
↓
客户有什么焦虑
↓
客户相信什么证据
↓
客户需要什么内容
↓
什么表达会转化
↓
什么表达有风险
```

## 7. 不要一开始做大而全

正确路线：

```text
先把刑事律师做深
↓
沉淀 legal template
↓
再复制到法律其他细分
↓
再选一个高客单行业扩展
```

## 8. 选择下一个行业的标准

优先选择：

```text
客单价高
专业表达门槛高
客户愿意为获客付费
内容能带来询盘
市场已经有人做短视频但效果不好
```

不建议优先选择：

```text
低客单价
高度同质化
客户不愿意付服务费
只追求低价流量
```
