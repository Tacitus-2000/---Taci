### 4.1 审查发现的问题

### 4.2 P1 问题修复详情

#### 1. ErrorMessage 缺少重试功能 ✅
- **影响**：所有 8 个页面
- **修复**：添加 `refetch` 回调
- **效果**：用户可以点击重试按钮，无需刷新页面

#### 2. Calendar 状态显示不友好 ✅
- **问题**：显示英文状态（draft, approved）
- **修复**：添加状态映射对象
- **效果**：显示中文标签（草稿、已通过）

#### 3. Dashboard 状态显示不友好 ✅
- **问题**：同 Calendar
- **修复**：添加状态映射对象
- **效果**：统一中文显示

#### 4. Feedback 缺少成功提示 ✅
- **问题**：只有 toast，缺少持久视觉反馈
- **修复**：添加成功提示卡片（5秒自动消失）
- **效果**：用户明确知道提交成功

#### 5. 分页缺少总数显示 ✅
- **影响**：Topics, Scripts 页面
- **修复**：显示数据范围（第 X 页 (起始-结束 条)）
- **效果**：用户了解数据量

#### 6. Generate 表单验证逻辑复杂 ✅
- **问题**：验证逻辑不清晰
- **修复**：优化 refine 逻辑，添加注释
- **效果**：代码更易维护
