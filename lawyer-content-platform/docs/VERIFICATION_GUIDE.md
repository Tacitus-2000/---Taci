## 八、问题排查

### 8.1 页面无法访问

**问题**：访问页面显示 404

**解决方案**：
1. 确认开发服务器正在运行
2. 检查 URL 是否正确
3. 清除浏览器缓存
4. 重启开发服务器

### 8.2 显示错误提示

**问题**：所有页面都显示错误

**可能原因**：
1. 后端 API 未配置
2. Supabase 连接失败
3. 测试数据不存在

**解决方案**：
1. 检查 `.env.local` 配置
2. 检查 Supabase 连接
3. 创建测试数据（参考 5.1）

### 8.3 表单提交失败

**问题**：点击提交后显示错误

**可能原因**：
1. 表单验证失败
2. API 请求失败
3. 数据库写入失败

**解决方案**：
1. 检查表单字段是否填写正确
2. 打开浏览器开发者工具查看网络请求
3. 检查后端 API 日志

### 8.4 AI 工作流不工作

**问题**：Generate 页面提交后失败

**可能原因**：
1. DeepSeek API Key 未配置
2. API Key 无效
3. 网络连接问题

**解决方案**：
1. 检查 `.env.local` 中的 API Key
2. 测试 API Key 是否有效
3. 检查网络连接
