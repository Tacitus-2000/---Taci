## 📋 项目背景

**当前版本**: V0.1 (2026-05-05)  
**当前状态**: Client API 认证授权已修复，页面可正常显示数据  
**下一版本**: V0.2 - AI 工作流集成

---

## 🎯 开发目标

根据用户选择，V0.2 版本的核心目标是：

1. **最高优先级**: 将所有 Mock Agent 替换为真实的 Claude API 调用
2. **LLM 提供商**: 使用 Anthropic Claude (claude-3-5-sonnet-20241022)
3. **补充功能**: 实现风格参考页面和提示词管理页面
4. **暂缓功能**: 行业模板系统（当前客户档案已足够）

## 阶段 0: 环境准备 (1-2 小时)

### 目标
配置 Claude API 和 LangChain 环境

### 任务清单
1. **安装依赖**
   ```bash
   npm install @anthropic-ai/sdk
   npm install langchain @langchain/anthropic
   ```

2. **配置环境变量**
   - 在 `.env.local` 添加：
     ```env
     ANTHROPIC_API_KEY=your_api_key_here
     LLM_MODEL=claude-3-5-sonnet-20241022
     LLM_TEMPERATURE=0.7
     LLM_MAX_TOKENS=4096
     ```

3. **创建 LLM 客户端配置**
   - 文件: `lib/ai/client.ts`
   - 初始化 Anthropic 客户端
   - 封装通用调用函数

4. **验证配置**
   - 创建测试脚本验证 API 连接
   - 确认 API Key 有效

### 验证标准
- ✅ 依赖安装成功
- ✅ 环境变量配置正确
- ✅ 测试调用返回正常响应

## 阶段 9: 数据持久化 (2-3 小时)

### 目标
将工作流执行结果保存到数据库

### 任务清单
1. **修改工作流服务**
   - 文件: `lib/services/workflow.service.ts`
   - 在工作流开始时创建 `agent_runs` 记录
   - 在每个步骤完成时创建 `agent_run_steps` 记录
   - 在工作流结束时更新 `agent_runs` 状态

2. **数据库操作**
   ```typescript
   // 创建工作流记录
   const { data: run } = await supabase
     .from('agent_runs')
     .insert({
       client_id: clientId,
       task_type: 'script_generation',
       status: 'running',
       input_summary: JSON.stringify({ topicId })
     })
     .select()
     .single();
   
   // 创建步骤记录
   await supabase
     .from('agent_run_steps')
     .insert({
       agent_run_id: run.id,
       agent_name: 'ScriptAgent',
       role: 'generator',
       input_payload: JSON.stringify(input),
       output_payload: JSON.stringify(output),
       status: 'completed'
     });
   ```

3. **状态同步**
   - 实时更新工作流状态
   - 记录错误信息
   - 记录执行时间
